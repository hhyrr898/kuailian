这篇按 Windows 10 22H2 和 Windows 11 23H2 的实际安装流程整理。很多人卡住不是下载步骤，而是安装包被浏览器拦截、系统权限没点允许，或者第一次连接时被防火墙挡住。

![快连下载 Windows 安装](https://tse-mm.bing.com/th?q=%E5%BF%AB%E8%BF%9E%E4%B8%8B%E8%BD%BD%20Windows%20%E5%AE%89%E8%A3%85)

## 安装前先看三件事

1. 系统尽量使用 Windows 10/11 64 位版本，老系统遇到驱动安装失败的概率更高。
2. 下载完成后先看文件名、文件大小和来源页面，不要运行来源不明的安装包。
3. 如果电脑装了第三方杀毒软件，安装时留意它是否拦截网络组件。

## 我会这样安装

先进入 [下载中心](/download.html) 选择 Windows 版。浏览器如果提示“此文件可能不常下载”，不要直接忽略，先确认自己是否从刚才的页面进入，再保留文件。

双击安装包后，Windows 可能弹出用户账户控制窗口。这里要确认发布者和文件名，再点允许。安装过程中如果出现网络适配器、驱动或防火墙提示，通常需要放行，否则后面客户端能打开但连不上。

安装结束后不要急着改节点，先用默认线路连接一次。托盘图标变为已连接后，打开两个常用网站测试。如果网页打不开，先断开重连一次，再看防火墙和 DNS。

## 常见卡点

**安装包打不开**  
右键选择“以管理员身份运行”。如果还是没反应，重新下载一次，优先排除文件没有下完整。

**客户端打开了但连接失败**  
先换手机热点测试。热点能连，说明公司网络、校园网或路由器策略可能有限制；热点也不行，再检查客户端版本和账号状态。

**连上后网页仍然超时**  
等 20 秒再刷新，或在命令提示符里执行 `ipconfig /flushdns` 清理 DNS 缓存。

## 安全核对

安装类页面最怕下错包。建议保留下载记录，安装完成后在客户端“关于”里看版本号；后续升级时也从同一个下载入口进入，不要点聊天软件里转发的安装链接。
