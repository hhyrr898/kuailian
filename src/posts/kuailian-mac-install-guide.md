我将在本文中演示快连 macOS 版 3.8.2（2024 年 11 月发布）的安装全过程。这篇文章会帮你解决安装时可能遇到的权限问题，并指导你完成首次连接，让你能马上用上这个工具。

本次测试环境为搭载 M1 芯片的 MacBook Air，系统版本是 macOS Sonoma 14.5。需要提醒的是，首次连接快连需要登录账号，如果你还没有注册，建议先准备好，这会让后续流程更顺畅。

安装前我习惯做两件事：确认系统时间自动同步、关闭其他代理类软件。前者影响证书校验，后者避免端口冲突。这些不是必须的，但能减少首次连接时的干扰。

## 下载与安装步骤

### 步骤 1：下载对应芯片的安装包

打开浏览器访问快连官网，找到 macOS 下载入口。页面会区分 Intel 和 Apple Silicon，我选的是 Apple Silicon 版本，文件大小约 86 MB。下载完成后在「下载」文件夹里能看到 `Kuailian_3.8.2_arm64.dmg`。

### 步骤 2：挂载磁盘映像并拖拽安装

双击 dmg 文件，系统会挂载一个虚拟磁盘。窗口里通常有两个图标：左边是快连应用，右边是 Applications 文件夹。把应用图标拖到 Applications 文件夹上，等待复制完成。这个过程大约 10 秒，进度条走完即可。

### 步骤 3：首次打开与安全提示处理

从「启动台」或「应用程序」文件夹打开快连。因为是从网络下载的应用，macOS 会弹窗提示「无法验证开发者」。这时不要点「移到废纸篓」，而是打开「系统设置 → 隐私与安全性」，在页面底部找到「仍要打开」按钮，点击后输入开机密码确认。之后再次打开应用就不会拦截了。

### 步骤 4：授予网络权限并登录

首次启动后，快连会请求添加 VPN 配置的权限，弹窗里点「允许」。接着进入登录界面，输入账号密码。如果登录后提示「无法连接」，可以先检查[快连连接失败修复方法](/posts/kuailian-connection-failed-fix/)，里面列了几个常见原因，我实测过其中两个都有效。

## 权限设置细节

macOS 对网络扩展的管控比较严，快连需要安装一个系统扩展才能建立连接。安装完成后，我建议手动检查两处：

- **系统设置 → 隐私与安全性 → 网络扩展**：确认快连的开关是打开的。
- **系统设置 → 通用 → 登录项与扩展**：看看是否有快连相关的后台项被禁用。

我第一次安装时忽略了第二处，结果连接按钮一直转圈。后来在登录项里把快连的后台进程启用，重新启动应用就正常了。这个细节在官方文档里没写，是我自己踩坑试出来的。

## 首次连接与节点选择

登录成功后主界面会显示当前节点。默认是「自动选择」，我一般先点连接，等状态变成「已连接」再测试网页打开速度。如果速度不理想，可以手动切换节点。关于节点选择的技巧，这篇[快连节点选择与速度优化](/posts/kuailian-node-selection-speed/)讲得比较细，我按照里面的方法把延迟从 180ms 降到了 90ms 左右。

连接成功后，菜单栏会出现快连的图标，点击可以查看当前连接时长和流量。我习惯在首次连接后打开一个测速网站跑一遍，确认下行速度正常。如果测速结果和裸连差不多，八成是节点没生效，断开重连一次通常能解决。

## 常见问题

### 安装时提示「应用已损坏，无法打开」怎么办？

这通常是下载过程中文件损坏，或者系统安全策略拦截。先重新下载一次安装包，确认文件大小和官网标注一致。如果还是报错，打开终端执行 `sudo xattr -rd com.apple.quarantine /Applications/Kuailian.app`，输入密码后重新打开应用。

### 首次连接一直显示「正在连接」然后失败？

先检查系统时间是否准确，误差超过几分钟会导致证书校验失败。其次确认网络扩展权限已开启。如果都没问题，尝试切换一个节点再连。我遇到过一次是本地 DNS 污染，手动把 DNS 改成 223.5.5.5 后恢复正常。

### 登录时提示账号密码错误，但网页能登录？

检查是否开启了输入法的大写锁定，或者复制密码时带了空格。另外，如果账号开启了二次验证，需要在密码后面追加验证码。具体规则可以参考[账号安全设置说明](/posts/account-security/)，里面提到了二次验证的填写格式。

### 连接成功后部分网站打不开？

先确认是全局模式还是规则模式。快连默认是规则模式，部分国内网站不走代理。如果某个国外网站打不开，可以在设置里切换为全局模式试试。另外，浏览器缓存也可能导致页面加载异常，开一个无痕窗口测试更准确。

## 写在最后

这台 Mac 上快连已经稳定用了两周，日常查资料和传文件都没出过问题。安装过程最花时间的其实是权限那几步，尤其是「仍要打开」按钮藏得比较深。如果你也在 macOS 上折腾过其他客户端，会发现快连的安装流程算简洁的。碰到连接问题别急着重装，先按上面的权限和节点顺序排查一遍，多数情况能自己解决。
